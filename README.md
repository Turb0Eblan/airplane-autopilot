# Airplane — автопилот самолёта

PlatformIO-проект с двумя прошивками:

| Окружение | Плата | Источник |
|-----------|-------|----------|
| `nano`  | Arduino Nano (ATmega328P) | `legacy/PilotExtended.ino` |
| `stm32` | STM32F103C8 (Blue Pill)   | `legacy/STM32Plane.ino` |

Функции: стабилизация по крену с BNO055 (элероны), возврат к точке старта по GPS
(руль направления, PID по ошибке курса), запись лога на SD-карту.

## Сборка и прошивка

```bash
pio run                      # собрать обе
pio run -e nano -t upload    # прошить Nano
pio run -e stm32 -t upload   # прошить STM32 через ST-Link
pio device monitor           # 115200
```

Если Nano не прошивается — в `platformio.ini` замените `nanoatmega328` на
`nanoatmega328new` (новый загрузчик).

## Подключение

### Arduino Nano
| Устройство | Пины |
|------------|------|
| GPS (9600) | D3 ← TX модуля, D2 → RX модуля |
| BNO055 (0x29) | A4 SDA, A5 SCL |
| SD-карта | D11 MOSI, D12 MISO, D13 SCK, D4 CS |
| Сервы | D7 левый элерон, D6 правый элерон, D8 руль |

### STM32 Blue Pill
| Устройство | Пины |
|------------|------|
| GPS (9600) | USART2: PA3 ← TX модуля, PA2 → RX модуля |
| Телеметрия (115200) | USART3: PB10 TX, PB11 RX |
| Отладка (115200) | USART1: PA9 TX, PA10 RX |
| BNO055 (0x29) | PB7 SDA, PB6 SCL |
| SD-карта | PA7 MOSI, PA6 MISO, PA5 SCK, PA4 CS |
| Сервы | PB13 левый элерон, PB14 правый элерон, PB15 руль |

## Дёргание серв на Nano при чтении GPS

**Причина.** `SoftwareSerial` на время приёма каждого байта (~1 мс на 9600 бод)
запрещает прерывания. `Servo` формирует импульсы в прерывании Timer1 — если оно
опаздывает, импульс удлиняется и серва дёргается. GPS шлёт пачку NMEA раз в
секунду, отсюда рывки раз в секунду. `detach()` серв на время чтения убирал
рывки, но и управление на это время пропадало.

**Исправление.** `SoftwareSerial` заменён на
[NeoSWSerial](https://github.com/SlashDevin/NeoSWSerial): у него короткий
обработчик прерывания, и он не держит прерывания запрещёнными, поэтому импульсы
`Servo` остаются ровными. Проводка не меняется. GPS читается непрерывно, без
`ss.begin()/ss.end()` и блокирующих окон.

Дополнительно исправлено в версии для Nano:
- `bno.begin()` вызывался в `controlServos()` каждые 20 мс и каждый раз
  перезапускал BNO055 — убран;
- `SD.begin()` вызывается один раз в `setup()`;
- ограничение интеграла PID (anti-windup), сброс PID при потере GPS;
- руль в нейтраль, если от GPS нет координат дольше 3 с.

**Если рывки всё же останутся** — самый надёжный вариант: подключить TX GPS к
аппаратному RX (D0) и читать через `Serial`. Минус: на время прошивки по USB GPS
нужно отключать.

## STM32

Исходный `STM32Plane.ino` не собирался (не были объявлены `rudderAngle`/`posz`,
GPS и `Serial2` были на одном USART2). Исправлено, телеметрия перенесена на
USART3, логика руля взята из PilotExtended. Убраны `while(!Serial)` и зависание
без SD-карты. Используется ядро STM32duino 4.x (класс `Uart`; в старых версиях
ядра он назывался `HardwareSerial`).
